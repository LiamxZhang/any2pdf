# Any2PDF Implementation Plan

> Execute inline with superpowers:executing-plans. User approved the design and requested bilingual failure explanations.

**Goal:** Deliver a portable local PDF converter with drag/drop, queue, history, Chinese/English UI and explicit conversion errors, and publish to the user's GitHub when authentication is available.

**Architecture:** PySide6 desktop launches isolated worker processes. SQLite stores structured results. Pillow, ReportLab and pypdf handle built-in formats; bundled LibreOffice and Playwright Chromium handle Office and HTML. Native CI builds portable archives.

**Tech Stack:** Python 3.12, PySide6, Pillow, ReportLab, pypdf, Playwright, PyInstaller, pytest, GitHub Actions. Use permissive PDF libraries rather than PyMuPDF to keep MIT application licensing straightforward.

## Acceptance

No silent conversion failures; history persists stable status/error codes and shows localized reason. No original files overwritten. A queued 10 GiB file is admitted without loading it; larger inputs fail before launching an engine. Cancellation terminates descendants. Native builds include runtime and engines, retain third-party licenses, and do not claim platform testing based on local Windows tests alone.
